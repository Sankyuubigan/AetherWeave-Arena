# Каталог Эффектов Заклинаний (Lego Bricks)

Здесь описаны все существующие атомарные эффекты (`Effects`), из которых мы собираем новые умения в файле `SkillDB.gd`. 
Используй этот каталог, чтобы понимать, какие механики уже реализованы, а какие нужно будет дописывать.

## 📦 Доступные строительные блоки (Реализовано)

### 1. `SpawnProjectileEffect`
Создает классический летящий по прямой снаряд.
* **Свойства:**
  * `projectile_scene` (PackedScene): Сцена самого снаряда (например, Огненный шар). Снаряд обязан иметь скрипт с функцией `set_direction(dir)`.
  * `offset_y` (float): Высота, на которой появляется снаряд относительно ног кастера (по умолчанию 1.2 метра, примерно из груди/рук).
* **Применение:** Обычные атаки, ледяные стрелы, снайперские выстрелы.

### 2. `SpawnHomingProjectileEffect`
Создает самонаводящийся враждебный снаряд.
* **Свойства:**
  * `projectile_scene` (PackedScene): Сцена самонаводящегося снаряда (Обязательно должен содержать скрипт с `set_target(target)` и `set_caster(caster)`).
  * `offset_y` (float): Смещение по высоте при спавне.
* **Применение:** Шаровые молнии, магические ракеты, духи, преследующие цель. *(Примечание: Умение должно иметь флаг `requires_target = true` и `target_type = "enemy"`).*

### 3. `SpawnHomingHealProjectileEffect`
Создает самонаводящийся снаряд, который не наносит урон, а вызывает функцию `heal()` у цели.
* **Свойства:**
  * `projectile_scene` (PackedScene): Сцена исцеляющего снаряда.
  * `offset_y` (float): Смещение по высоте.
* **Применение:** Саппортские скиллы, лечение союзников. *(Примечание: Умение должно иметь флаг `requires_target = true` и `target_type = "friendly"`).*

### 4. `AoeDamageEffect`
Мгновенно наносит урон всем целям в заданном радиусе (AoE) от точки прицела.
* **Свойства:**
  * `radius` (float): Радиус взрыва (в метрах).
  * `damage` (int): Количество наносимого урона.
  * `vfx_scene` (PackedScene): (Опционально) Сцена с GPUParticles3D, которая появится в месте взрыва (например, удар молнии или взрыв метеорита).
* **Применение:** Гранаты, взрывы, заклинания по площади.

### 5. `TeleportEffect`
Мгновенно перемещает кастера в точку, куда он целится.
* **Свойства:**
  * `vfx_scene` (PackedScene): (Опционально) Сцена вспышки, которая появится в точке старта и в точке прибытия.
* **Применение:** Блинки, прыжки сквозь пространство.

### 6. `PlaySoundEffect`
Воспроизводит любой звуковой файл в мире. Незаменим для композиции, чтобы добавить звук к скиллам, у которых нет своего встроенного звука при касте.
* **Свойства:**
  * `audio_stream` (AudioStream): Звуковой файл (`.ogg` или `.wav`).
  * `volume_db` (float): Громкость (по умолчанию 0.0).
* **Применение:** Озвучка каста, боевые крики.

## 🚧 Список желаемого (Что предстоит создать в будущем)

Если ты придумываешь скилл и понимаешь, что нужной детальки тут нет, значит нужно написать новый скрипт-наследник `Effect.gd`. 

**Идеи для будущих эффектов:**
* `RaycastDamageEffect` — Hitscan урон (как лазер или снайперская пуля), мгновенное попадание по линии взгляда.
* `BuffEffect` / `DebuffEffect` — Изменение статов (скорости, защиты) на время (потребует системы баффов в логике `HealthComponent`).
* `ShieldEffect` — Создание непробиваемого щита, блокирующего снаряды.
* `ChainLightningEffect` — Эффект, который находит цель, а затем прыгает на ближайших врагов.
* `SpawnSummonEffect` — Спавн союзного AI-помощника в точке прицела.

## 🛠 Пример сборки сложного заклинания (Паттерн Лего)
Допустим, мы хотим создать **"Ультимативный Метеоритный Скачок"**. 
Мы хотим, чтобы игрок телепортировался в толпу врагов, при появлении происходил взрыв, наносящий огромный урон, и всё это сопровождалось громким звуком.

```gdscript
var ult = Skill.new()
ult.id = "meteor_blink"
ult.skill_name = "Метеоритный Скачок"

# Деталь 1: Телепортируем игрока в точку прицела
var blink = TeleportEffect.new()
blink.vfx_scene = load("res://Scenes/teleport_effect.tscn")
ult.effects.append(blink)

# Деталь 2: Взрыв по площади (урон нанесется вокруг НОВОЙ позиции)
var boom = AoeDamageEffect.new()
boom.radius = 10.0
boom.damage = 100
boom.vfx_scene = load("res://Scenes/thunder_effect.tscn")
ult.effects.append(boom)

# Деталь 3: Звук
var sound = PlaySoundEffect.new()
sound.audio_stream = load("res://Audio/SFX/huge_explosion.ogg")
ult.effects.append(sound)

_skills["meteor_blink"] = ult
```
Как видишь, для создания такой сложной механики нам **вообще не потребовалось писать новый код**. Мы просто сложили существующие кирпичики!
